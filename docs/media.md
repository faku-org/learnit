# Supplementary media (issue #9)

Examples were text-only. Languages in particular need a picture for context and a recording for pronunciation.
A topic now has an optional **Supplementary material** panel (collapsed by default).

## Flow

1. `LearnPage` renders `TopicMedia` for the topic on screen. Nothing is requested until the student opens it.
2. `GET /api/path/:id/module/:order/topic/:index/media` (auth, per-user path lookup via `forUser`) resolves the
   topic and calls `resolveMedia` (`api/src/sources/media.ts`).
3. `resolveMedia` consults the providers in `DomainSpec.mediaProviders` (languages: `commons`; every other subject:
   none, so no network call). Results are cached in the shared `media_queries` (30 days; 3 days when empty) and
   `media` collections. An unreachable provider is never cached and never fails the lesson (`{ blocks: [] }`).
4. Every result is passed through `sanitizeBlocks(..., ["media"])` before it leaves the server.

## Providers

| Provider | What | Key | Notes |
|---|---|---|---|
| `commons` | images, pronunciation audio, video | none | Wikimedia Commons API. Only open licenses (CC BY/BY-SA/CC0/PD/GFDL), an author is mandatory, files with `Restrictions` or unexpected MIME types are dropped, videos over 40 MB are dropped. |
| `youtube` | one video | none | No search and no scraping: only when a `youtubeId` is supplied. Verified through oEmbed, the title must share a word with the topic. Rendered as `youtube-nocookie.com` behind a click. Stores no URL, only the id. |

Nothing proposes a `youtubeId` yet; the provider is in place for when a curated source of ids exists.

## Security

The `media` block is **not** generated by the model: no domain lists it in `blocks`. The sanitizer still treats it as
hostile input because the bank is shared across users: files must be `https` on `upload.wikimedia.org` /
`thumb.wikimedia.org`, pages on `commons.wikimedia.org`, YouTube ids must match `^[A-Za-z0-9_-]{11}$`, and a license
is required.

## Attribution

Each block shows title, author, license (linked when the license URL is known) and a link to the source page.
